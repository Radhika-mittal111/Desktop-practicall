## Objective
To practise selecting a clear subject, refining selection edges, applying non-destructive colour corrections with adjustment layers and masks, and comparing the original and edited versions.

## Step 1: Open the Photograph
1. Open Adobe Photoshop.
2. Choose **File → Open** and select a photograph with a clearly identifiable subject.
3. Save a working copy using **File → Save As** so the original remains unchanged.

## Step 2: Select the Main Subject
1. Choose the **Quick Selection Tool**, **Magic Wand Tool**, or **Lasso Tool** from the Toolbar.
2. Carefully select the main subject.
3. With the Lasso Tool, trace around the subject; with Quick Selection, brush over the subject; with Magic Wand, click a consistently coloured area.
4. Hold **Shift** to add areas and **Alt/Option** to subtract areas where supported.

## Step 3: Refine the Selection Edges
1. Zoom in around the subject edges.
2. Use the Lasso Tool or selection options to correct missed or extra areas.
3. In versions that provide **Select and Mask** or **Refine Edge**, use it to smooth edges and reduce halos.
4. In Photoshop 7.0, which may not have Select and Mask, use **Select → Feather** with a very small value (about 1–2 px) where appropriate.
5. Inspect fine edges at 100% zoom before continuing.

## Step 4: Create the First Adjustment Layer
1. Keep the subject selection active.
2. Choose **Layer → New Adjustment Layer → Brightness/Contrast** (or the equivalent adjustment-layer menu in your version).
3. Name the layer **Subject_Brightness_Contrast**.
4. Adjust brightness and contrast gradually until the subject is clearer.
5. Confirm the adjustment. The selection should limit the adjustment to the selected region through its mask.

## Step 5: Create a Second Adjustment Layer
1. Choose **Layer → New Adjustment Layer → Hue/Saturation** or **Color Balance**.
2. Name it **Subject_Color_Correction**.
3. Adjust saturation, hue, or colour balance carefully; avoid unnatural colours.
4. If the adjustment affects the wrong area, click its layer mask and correct it using a soft Brush: black hides the adjustment, white reveals it, and grey applies it partially.

## Step 6: Adjust the Background (Optional)
1. Select the background area by inverting the subject selection with **Select → Inverse**.
2. Add another adjustment layer, such as **Levels** or **Curves**.
3. Make a subtle background adjustment to separate the subject from its surroundings.
4. Use the adjustment mask to keep the subject's appearance protected.

## Step 7: Prepare Original and Edited Versions
1. Keep an untouched copy of the original photo named **Original**.
2. Create a comparison layout with the original on one side and edited version on the other.
3. Add labels **ORIGINAL** and **EDITED** using the Type Tool (T).
4. Add your student details: **Radhika Mittal**, **CU25260169**, **BCA**.
5. Check that the comparison is balanced and all text is readable.

## Step 8: Review Layers and Masks
1. Rename layers clearly.
2. Ensure there are at least two adjustment layers.
3. Click each adjustment layer's mask thumbnail and inspect the black/white mask.
4. Toggle visibility to compare the effect before and after each adjustment.
5. Keep the original photo layer unchanged for a fair comparison.

2. Use the filename `Practical_04_Radhika_Mittal_CU25260169.psd`.
3. Choose **Photoshop (*.PSD)** and save with layers preserved.
4. Do not flatten the working PSD.

2. Select **JPEG/JPG**.
3. Use the filename `Practical_04_Radhika_Mittal_CU25260169.jpg`.
